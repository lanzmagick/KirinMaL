# KirinMaL v1.0.14 — RGB Progress

## Highlights
- Port RGB progress color stages from KirinList to KirinMaL.
- Add a six-stage color progression for anime and manga list progress.
- Add a Settings toggle to enable or disable RGB progress colors.

## Improvements
- RGB progress colors apply to Standard, Compact, Minimal and Grid list layouts.
- Standard layout progress bar uses the matching stage color.
- Progress tint supports media entries with unknown totals using count-based milestones.
- RGB progress preference is persisted and enabled by default.

## Fixes
- Keep the normal theme progress tint when RGB progress is disabled or progress is zero.
