# KirinMaL v1.0.0 — First Stable Release

**12 Oktober 2026 · Android · Build 407**

Selamat datang ke **KirinMaL**! Ini keluaran stabil pertama bagi aplikasi anime dan manga yang disesuaikan daripada **MoeListKMP**, dengan fokus pada akaun **MyAnimeList (MAL)**, penemuan tajuk dan antaramuka yang lebih kemas.

## ✨ 1. Identiti KirinMaL

- Nama aplikasi, pautan projek, ikon dan identiti visual ditukar kepada **KirinMaL**.
- Logo naga KirinMaL digunakan pada launcher Android, splash, About, More dan aset untuk platform lain.
- Tampilan baharu mengekalkan gaya aplikasi asal sambil menyelaraskan elemen UI dan warna.
- GitHub Pages rasmi diperkenalkan: [Website KirinMaL](https://lanzmagick.github.io/KirinMaL/), dengan laman responsive yang ringkas dan tanpa galeri screenshot.

## 🔗 2. Akaun MAL, status dan statistik

- Senarai **Anime dan Manga** terus disambungkan kepada akaun **MyAnimeList** — perubahan status disimpan pada MAL, bukan AniList.
- Status **Watching / Reading, Plan to Watch (PTW), Plan to Read (PTR), Completed, On Hold dan Dropped** disokong melalui editor MAL.
- Badge status di Home, Seasonal, Ranking, Search dan kad media lain mengambil data daripada senarai akaun selepas login. Senarai panjang dimuatkan merentasi beberapa halaman MAL.
- Selepas Add/Edit, status badge diselaraskan serta senarai anime/manga dikemas kini tanpa perlu login semula.
- **Anime Stats dan Manga Stats** bergaya statistik MAL/KirinNime ditambah pada profil, termasuk jumlah tontonan/bacaan dan kemajuan; Manga Stats mempunyai fallback senarai MAL berhalaman.

## 🧭 3. Anime Menu, Manga Menu dan Genres

- **Anime Menu** dan **Manga Menu** mengekalkan tab ranking MAL, dengan satu tab tambahan **Genres** — tiada lagi deretan tab genre terlalu panjang.
- Genres dipaparkan dalam **kad bento responsive** dan diasingkan kepada *Genres*, *Themes*, *Demographics* serta *Explicit Genres*.
- Menggunakan senarai kategori gaya MAL: **76 kategori Anime** dan **78 kategori Manga**.
- Carian genre dan tag menggunakan **API AniList** untuk menemukan tajuk, tetapi hanya tajuk yang mempunyai **ID MAL (idMal)** boleh dibuka untuk penyuntingan senarai MAL.
- Kategori matang/18+ tersedia mengikut tetapan **NSFW**, yang boleh dihidupkan atau dimatikan dalam Settings.
- Navigasi Back diperkemas: **Genres → hasil genre → info anime/manga → Back ke hasil genre yang sama → Back ke bento Genres**.

## 🎨 4. Penambahbaikan Home dan interaksi kad

- **Search bar Home kekal di bahagian atas** ketika kandungan discroll, seperti tingkah laku aplikasi asal.
- Menu status terapung ditukar kepada **susunan bento dua lajur**, tanpa latar kotak besar; menu terakhir memenuhi ruang baris.
- **Tekan lama kad anime/manga** atau ketuk badge status untuk terus membuka **sheet Add/Edit MAL** di Home dan bahagian penemuan lain.
- Sheet Quick Edit kini **terbuka separuh skrin secara lalai** supaya halaman di belakang masih kelihatan; tarik ke atas untuk melihat pilihan lanjut.
- Pembetulan pada paparan badge, keadaan editor apabila menukar tajuk, dan refresh selepas perubahan status.

## 📦 5. First Release Android

- **v1.0.0 ialah keluaran Android release yang ditandatangani**, bukan APK debug.
- Pilihan APK mengikut peranti: **ARM64-v8a**, **armeabi-v7a**, **x86**, **x86_64** dan **Universal**.
- APK disediakan terus di **GitHub Releases**, bukan Actions Artifacts; aliran debug lama telah dihentikan.
- Proses build menyemak kunci signing dan mengesahkan tandatangan APK sebelum penerbitan.

### 📲 APK mana perlu dipilih?

- **ARM64-v8a** — kebanyakan telefon Android moden (pilihan yang disyorkan).
- **armeabi-v7a** — telefon Android 32-bit yang lebih lama.
- **Universal** — jika tidak pasti seni bina peranti.
- **x86 / x86_64** — untuk peranti atau emulator yang berkenaan.

**Nota penting:** APK debug lama menggunakan ID pakej berbeza daripada release stabil, jadi ia mungkin dipasang sebagai aplikasi berasingan. Pastikan data setempat disandarkan sebelum menukar pemasangan. Padanan genre/tag AniList tidak sentiasa 1:1 dengan MAL, maka sesetengah kategori mungkin mempunyai hasil yang terhad.
