# KirinMaL v1.0.7 — Magic Home & Genre MAL

- Dua butang **Magic Anime** dan **Magic Manga** di Home mendapat partikel yang bergerak mengelilingi border, jejak cahaya dan pantulan kaca menyerong.
- Anime menggunakan warna **ungu–biru**, Manga **merah jambu–emas**. Kedua-duanya menyesuaikan tema cerah/gelap dan kekal sama saiz dengan bento Home **60 dp**. Animasi berterusan berhenti apabila entri navigasi tidak aktif.
- Genre anime dan manga kembali menggunakan **nama dan ID kategori asal MyAnimeList melalui Jikan v4**: Genres, Themes, Demographics dan Explicit Genres. Padanan genre/tag AniList digantikan.
- Pemilihan kategori mencari tajuk menggunakan ID genre MAL sebenar, diasingkan mengikut anime/manga, dengan skor MAL **/10** dan susunan mengikut bilangan ahli.
- Katalog kategori lengkap yang berjaya dimuat disimpan dalam cache memori selama enam jam. Paging, retry halaman gagal, penyingkiran ID berulang dan filter NSFW dikekalkan.
- Permintaan Jikan awam menggunakan sela permintaan bersama dan tidak membawa header OAuth MAL.
- Popup/pemilihan Magic, butang Random/Magic dalam senarai, bento Home, callback login MAL dan penyuntingan senarai mengekalkan logik sedia ada.
