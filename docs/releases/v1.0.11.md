# KirinMaL v1.0.11 — Ikon Menu Senarai

- Kawalan dropdown di kanan search bar Anime dan Manga menggunakan **ikon tiga garis sahaja**, mengikut gaya list AniHyou.
- Label pilihan seperti **Last updated** dan bingkai chip pada bar atas dibuang. Nama pilihan serta tanda pilihan semasa dipaparkan apabila menu dibuka.
- Ikon **24 dp** menggunakan kawasan sentuh **48 dp** dan menyesuaikan tema app. Search bar mendapat lebih ruang.
- Nama pilihan semasa kekal tersedia kepada pembaca skrin.
- Pembetulan padanan tab dalam v1.0.10, simpanan pilihan Anime/Manga yang berasingan serta menu Title, Score, Last updated dan Start date dikekalkan.
- Penapis A–Z, Random asal dan Magic kekal di toolbar senarai. Tiada perubahan pada OAuth/login MAL, permission atau dependency runtime.

## Versi dan build

- Version name **1.0.11**, version code **418**.
- Workflow menjalankan ujian regresi dropdown/tab, Magic shuffle, simpanan tetapan Magic dan Recommended Manga sebelum membina serta mengaudit APK signed.
- APK menggunakan signing secrets repo semasa dan tersedia dalam **arm64-v8a, armeabi-v7a, x86, x86_64 dan universal**.
- iOS dan Desktop kekal **Coming soon**.
