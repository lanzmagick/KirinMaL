# KirinMaL v1.0.3 — Genres & MAL Client ID sendiri

## Fix Genres — Anime & Manga

- Betulkan kategori terakhir **Explicit** yang tertutup oleh garisan navigasi Android.
- Tambah ruang bawah secara dinamik mengikut `WindowInsets.safeDrawing` ditambah **80dp** pada grid kategori, supaya bahagian terakhir boleh discroll sepenuhnya ke atas dengan ruang yang jelas.
- Senarai tajuk selepas memilih genre juga mendapat ruang bawah mengikut inset sistem dan tambahan **64dp**.
- Berlaku untuk **Anime Menu** dan **Manga Menu**, termasuk peranti dengan butang navigasi atau gesture bar.

## MyAnimeList Client ID milik sendiri

- Android tidak lagi menggunakan OAuth Client ID asal MoeList.
- KirinMaL membaca `MAL_CLIENT_ID` daripada GitHub Actions Secrets sewaktu build signed, atau `private.properties` untuk build tempatan.
- Workflow release akan berhenti dengan mesej jelas jika Client ID pemilik belum dimasukkan. **Tidak akan menerbitkan APK yang menggunakan ID orang lain.**
- Cara pendaftaran MAL API: [MyAnimeList API applications](https://myanimelist.net/apiconfig).
- Redirect URL untuk pendaftaran Client ID: `kirinmal://oauth/mal`.
- Daftarkan aplikasi MAL **KirinMaL** dengan redirect ini; KirinNime menggunakan redirect berbeza, `kirinime://oauth/mal`.
- Selepas Client ID berubah, mungkin perlu login MAL semula.

## Dikekalkan

- Package Android sendiri: `com.lanzmagick.kirinmal`.
- Release APK rasmi ditandatangani, diaudit dan dimuat naik **ke GitHub Releases sahaja**, bukan Actions Artifacts.
- Semua fungsi MAL Sync, Quick Edit, Ranking, Genre Discovery, Seasonal, statistik, dan branding KirinMaL yang telah ditambah sebelum ini dikekalkan.
