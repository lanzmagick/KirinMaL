# KirinMaL v1.0.6 — Menu Home Lebih Kecil

- Kecilkan keenam-enam kad Home: **Anime Menu, Manga Menu, Seasonal Chart, Calendar, Magic Anime dan Magic Manga**.
- Tinggi kad dikurangkan daripada **84 dp kepada 60 dp** supaya slot anime dan manga di bawahnya lebih cepat kelihatan.
- Padding kini **12 dp mendatar / 8 dp menegak**, ikon **20 dp** dan sudut kad **18 dp**. Saiz teks dikekalkan.
- Semua kad kekal sama saiz, dengan dua kolum pada telefon dan tiga kolum pada skrin besar. Jarak dan susunan menu dikekalkan.
- Fungsi navigasi, popup Magic, carousel Home, login MAL, toggle About dan border RGB tidak berubah.
