# KirinMaL v1.0.5 — Home Bento, Recommended Manga & RGB Border

## Home

- Buang butang Random Anime dan Random Manga daripada Home; kekalkan **Magic Anime** dan **Magic Manga** dengan popup kejutan sedia ada.
- Enam shortcut Home berkongsi bento bersaiz seragam: **Anime Menu, Manga Menu, Seasonal Chart, Calendar, Magic Anime dan Magic Manga**. Dua kolum pada telefon dan tiga kolum pada skrin besar, tinggi kad 84 dp dan jarak 8 dp.
- Buang slot Popular Manga dan Top Rated Manga daripada Home. Kedua-dua ranking masih tersedia dalam Manga Menu.
- Susunan slot peribadi selepas bento: **Recent Watching Anime → Reading Manga → Recommended Manga**. Slot muncul selepas login.
- Recent Watching Anime mengambil sehingga 25 tajuk Watching mengikut kemas kini MAL terbaru, dengan progress episod dan badge status. Tekan tajuk slot untuk membuka list Watching.
- Recommended Manga menggabungkan cadangan MAL daripada sehingga tiga manga Reading yang baru dikemas kini, atau Completed jika Reading kosong. Jumlah undian cadangan digabungkan; ID berganda dan manga yang sudah berada dalam mana-mana status list pengguna dikecualikan.
- Home memaparkan sehingga 25 cadangan manga; anak panah membuka grid penuh sehingga 100 cadangan daripada sumber yang sama.
- Slot ikut bahasa tajuk, Hide Scores dan NSFW, mempunyai keadaan kosong/Retry, refresh selepas Quick Edit dan mengosongkan data peribadi ketika logout.
- Slot Recommendations anime sedia ada kekal menggunakan cadangan akaun MAL.

## Anime & Manga List

- Label filter permulaan tajuk kini **Sort : All**, **Sort : A**, **Sort : 1** atau **Sort : #**, mengikut pilihan pengguna.
- Magic kekal muncul walaupun toggle **Random button on anime/manga list** dimatikan. Toggle hanya mengawal butang Random asal; logik Random dan pilihan yang disimpan dikekalkan.
- Border 1.5 dp pada kotak status terpilih menggunakan warna RGB cerah secara rawak setiap kali status bertukar. Warna baru berbeza sekurang-kurangnya 60 darjah hue; membuka/tutup menu tidak memilih warna semula.
- Warna MAL pada kotak status, teks/ikon, bayang dan logik pemilihan status dikekalkan.

## Login & About

- Kemaskan paparan login MAL dengan tajuk MyAnimeList, ikon buku, butang biru **Continue with MyAnimeList**, monogram MAL dan anak panah. Layout boleh discroll pada skrin kecil.
- Callback login, `continueLogin()`, OAuth, redirect, Client ID dan token handling dikekalkan.
- Tambah **Settings → Display → Show About menu**, default **OFF**. Hanya sembunyikan pintasan About dalam More; halaman About, pautan dan kredit asal axiel7 kekal apabila toggle dihidupkan.

## GitHub Pages

- Laman [KirinMaL](https://lanzmagick.github.io/KirinMaL/) mengekalkan muat turun Android dan menambah kad **iOS — Coming soon** serta **Desktop — Coming soon**.
- Kad platform ikut susunan responsif untuk telefon dan desktop. Release ini menerbitkan APK Android sahaja.

## Versi & Pengesahan

- Version name **1.0.5**, version code **412**.
- Workflow release menjalankan ujian Magic shuffle bag dan pemilihan Recommended Manga sebelum build signed APK.
- Semua APK disemak untuk tandatangan release, package ID, manifest dan permissions sebelum diterbitkan.
- Package Android **com.lanzmagick.kirinmal** dan redirect MAL **kirinmal://oauth/mal**. APK mengemas kini pemasangan KirinMaL v1.0.1 dan seterusnya menggunakan signing key yang sama.
- Pilihan APK: **arm64-v8a, armeabi-v7a, x86, x86_64 dan universal**.
- Kredit Netflix Kids' Mystery Box dan logik Magic kekal dalam [README](https://github.com/lanzmagick/KirinMaL#magic-discovery-inspiration-and-picker-logic).
