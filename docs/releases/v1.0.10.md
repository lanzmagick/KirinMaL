# KirinMaL v1.0.10 — Pulihkan Dropdown Last Updated

- Dropdown asal susunan senarai dipaparkan di sebelah kanan search bar untuk list **Anime dan Manga**, dengan label pilihan semasa seperti **Last updated**.
- Betulkan padanan tab supaya instans tab Anime/Manga dikenal pasti dengan betul. Dalam v1.0.9, padanan yang salah menyembunyikan dropdown baharu sedangkan kawalan lama sudah dipindahkan.
- Bentuk butang berlabel dipulihkan supaya menu asal mudah dikenal pasti. Menu **Title, Score, Last updated dan Start date** serta tanda pilihan semasa dikekalkan.
- Butang tapisan huruf **Sort: All/A–Z**, Random asal dan Magic kekal di toolbar senarai; tetapan serta logik masing-masing dikekalkan.
- Pilihan susunan Anime dan Manga terus disimpan berasingan dan digunakan semasa memuat semula senarai.
- Empat ujian regresi meliputi tab Anime/Manga sebenar, instans tab yang dipulihkan, keadaan belum login dan halaman lain. Workflow release menjalankan ujian ini sebelum membina APK.
