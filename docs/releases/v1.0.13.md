# KirinMaL v1.0.13 — Startup dan Search Bar

- Membetulkan halaman login MAL yang muncul sekejap apabila app dibuka dengan sesi tersimpan. App kini membezakan sesi yang masih dimuat daripada keadaan benar-benar belum login.
- Splash screen Android kekal sehingga bacaan sesi tempatan selesai, tanpa kelewatan tetap atau menunggu rangkaian. Migrasi token lama yang sedia ada diselesaikan sebelum app menentukan status sesi.
- Search bar list **Anime dan Manga** mengekalkan ruang menu sort sepanjang animasi keluar ke Search supaya bar tidak memanjang secara tiba-tiba apabila menu sort hilang.
- Pertukaran tab Anime/Manga mengemas kini kandungan bar tanpa memainkan semula animasi buka/tutup. Search dari list Manga kini bermula dengan jenis Manga; Home kekal Anime.
- Menu Last updated, simpanan sort berasingan, penapis A–Z, Random asal, Magic, border RGB serta tetapan sedia ada dikekalkan.
- Callback OAuth MAL, refresh token, penyimpanan token dan logout menggunakan logik asal. Tiada permission atau dependency runtime baharu.
