# KirinMaL v1.0.4 — Magic Anime/Manga, Home Manga & Filter List

## Random & Magic Anime/Manga

- Butang **Magic** di sebelah Random pada kedua-dua list Anime dan Manga. Susunan kawalan: Sort → filter A–Z/1–0/simbol → Random → Magic; Random default list masih menggunakan tingkah laku sedia ada.
- Tekan Magic untuk popup kotak berwarna dengan animasi sparkle/pulse, kemudian reveal poster dan tajuk pilihan. **Open info** membuka Anime/Manga Info; **Surprise me again** memberi pilihan seterusnya.
- Magic list mengambil semua halaman status MAL yang dipilih dan ikut filter permulaan tajuk serta bahasa tajuk pengguna.
- Home kini mempunyai **Random Anime / Magic Anime** dan **Random Manga / Magic Manga**. Pilihan diambil daripada gabungan sehingga 100 hasil Popularity + 100 hasil Score MAL bagi jenis berkenaan, dengan ID berganda dibuang.
- Pemilihan Home menggunakan ID sah daripada respons MAL. Butang Random membuka info terus, manakala Magic reveal dalam popup dahulu.
- Shuffled bag memberikan setiap calon satu giliran sebelum diisi semula; elak tajuk sama berturut-turut jika ada sekurang-kurangnya dua calon. Buka semula untuk muat data baru; pilihan Again menggunakan bag semasa.
- Pemuatan boleh dibatalkan dengan menutup popup, dan hasil kosong/permintaan gagal mempunyai mesej serta cubaan semula. Pilihan ikut tetapan NSFW pengguna.
- Kredit kepada **Netflix Kids' Mystery Box** untuk inspirasi interaksi kejutan. Pautan rujukan, skop calon MAL dan logik picker KirinMaL diterangkan dalam [README](../../README.md#magic-discovery-inspiration-and-picker-logic).

## Slot Manga di Home

- Tambah tiga carousel manga, masing-masing sehingga **25 tajuk** daripada API MAL.
- **Reading Manga:** tajuk dalam status Reading milik pengguna, disusun mengikut kemas kini terbaru. Paparkan progress chapter atau volume dan refresh selepas Quick Edit; slot ini muncul selepas login.
- **Popular Manga:** ranking Popularity MAL dengan jumlah Members pada kad.
- **Top Rated Manga:** ranking skor MAL, dengan paparan skor mengikut tetapan Hide Scores.
- Slot Reading berada selepas shortcut Home; Popular dan Top Rated selepas slot Recommendations anime.
- Setiap tajuk membuka Manga Info; tekan lama/badge menggunakan Quick Edit MAL sedia ada.
- Anak panah tajuk membuka senarai penuh yang sepadan: Reading, Popularity atau Score.
- Setiap slot memuat secara berasingan dan mempunyai Retry apabila permintaan gagal. Semua slot ikut bahasa tajuk dan tetapan NSFW pengguna.

## Anime & Manga List

- Tambah pilihan **A–Z, 1–0 dan simbol** di sebelah Sort. Pilih huruf/nombor untuk menapis permulaan tajuk; **All titles** membuang filter.
- Filter ikut bahasa tajuk yang dipaparkan dan membaca baki halaman MAL supaya tajuk pada halaman kemudian tetap ditemui.
- Pilihan simbol turut meliputi permulaan tajuk selain huruf Latin/nombor 0–9, termasuk tajuk Jepun.
- Kawalan yang sama tersedia dalam tampilan Standard, Compact, Minimal dan Grid, untuk telefon serta tablet. Bar kawalan boleh discroll mendatar pada skrin sempit.
- Pilihan filter dikekalkan apabila menukar status, dan pertukaran filter membawa scroll kembali ke kawalan list.
- Paparkan keputusan kosong hanya selepas pemuatan selesai. Jika pemuatan gagal, tunjuk mesej serta butang Retry.
