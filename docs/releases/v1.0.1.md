# KirinMaL v1.0.1 — Android identity fix

KirinMaL now has its **own Android package ID: `com.lanzmagick.kirinmal`**.

- Fixed accidental package collision with the original MoeList Android app (`com.axiel7.moelist`).
- Updated launcher, application and widget component names to resolve correctly under the new install identity.
- Updated home, anime and manga app shortcuts to launch KirinMaL instead of MoeList.
- Kept the MyAnimeList OAuth redirect unchanged for compatibility; MAL sign-in must be completed again on this new installation.
- Signed Android Release APKs built using the existing KirinMaL signing keystore, with no debug APKs published.

**Installation note:** v1.0.1 installs as a separate application from v1.0.0 and MoeList. Local data is not transferred automatically, but your anime and manga list remains in your MyAnimeList account. If both old and new apps are installed, Android may ask which app should handle the MAL login redirect.
