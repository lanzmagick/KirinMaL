# KirinMaL v1.0.2 — Audit keselamatan APK Release

## Perubahan

- Audit fail APK yang sudah dibina dan ditandatangani sebelum dilepaskan.
- Semak identiti aplikasi `com.lanzmagick.kirinmal`, target Android moden dan pastikan APK bukan `debuggable`.
- Semak permissions daripada APK gabungan termasuk library, menghalang release jika mengandungi permission sensitif SMS, Accessibility, Notification Listener, atau pemasangan APK.
- Semak ZIP/APK, sijil signing yang konsisten, Android v2 signature dan checksum SHA-256.
- Kekalkan metadata Android SDK dependencies standard untuk ketelusan.
- Kekalkan semua fungsi anime/manga sedia ada, MAL sync, genres, quick edit, seasonal, ranking dan KirinMaL branding.

## Play Protect

Perubahan ini membantu mengenal pasti kesilapan pemasangan dan permissions yang berisiko. **Ia bukan jaminan bahawa Google Play Protect tidak lagi memaparkan amaran**. Jika disekat lagi, catat mesej tepat dan [semak panduan rasmi Google](https://developers.google.com/android/play-protect/warning-dev-guidance); mungkin perlu semakan/appeal Google. Jangan matikan Play Protect.

## Download

**ARM64** sesuai untuk kebanyakan telefon moden; **Universal** disediakan jika tidak pasti. Semua APK ditandatangani dan diterbitkan melalui GitHub Releases, bukan Artifacts.
