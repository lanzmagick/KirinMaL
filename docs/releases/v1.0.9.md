# KirinMaL v1.0.9 — Sort di Sebelah Search

- Dropdown susunan **Last updated, Title, Score dan Start date** untuk kedua-dua list Anime dan Manga kini dibuka melalui ikon sort di kanan search bar pada tampilan telefon.
- Search bar menyesuaikan lebarnya, avatar profil dikekalkan dan ikon sort mempunyai kawasan sentuh 56 dp.
- Pilihan semasa ditandakan dalam dropdown. Pilihan Anime dan Manga disimpan berasingan menggunakan tetapan sort sedia ada.
- List aktif serta tab status yang disimpan mengikut perubahan sort, memulakan semula pagination dan mengekalkan pilihan status serta penapis huruf.
- Sort di baris lama disembunyikan apabila kawalan search bar digunakan. Tampilan tablet/desktop dan halaman senarai tanpa search bar mengekalkan kawalan sort sedia ada.
- Butang Random, Magic dan penapis huruf kekal pada toolbar senarai. Tiada perubahan kepada OAuth/login MAL, permission Android atau dependency runtime.
- Helper **KIRINMAL-PASSWORD.cmd** dalam source menyediakan alias dan butiran sijil secara automatik; pengguna hanya memasukkan password untuk menjana key sendiri.

## Versi dan build

- Version name **1.0.9**, version code **416**.
- APK release ditandatangani menggunakan signing secrets yang dikonfigurasikan dalam repo.
- Workflow menjalankan ujian Magic shuffle, simpanan tetapan Magic dan Recommended Manga, kemudian membina serta mengaudit tandatangan, manifest, permission dan identiti APK sebelum penerbitan.
- Varian APK: **arm64-v8a, armeabi-v7a, x86, x86_64 dan universal**.
