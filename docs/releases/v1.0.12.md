# KirinMaL v1.0.12 — RGB FAB dan Floating Menu

- FAB pembuka popup status pada list **Anime dan Manga** mendapat border RGB **1.5 dp**, berkongsi warna dengan border kotak status terpilih.
- Warna border bertukar secara rawak setiap kali FAB ditekan untuk membuka atau menutup menu.
- Setiap pilihan status dalam popup menukar border juga, termasuk apabila status yang sama ditekan semula.
- Pertukaran status dari luar popup terus menukar border. Pilihan status melalui popup tidak memilih warna dua kali untuk satu pertukaran status.
- Setiap perubahan hue berjarak sekurang-kurangnya **60 darjah** supaya warna baharu berbeza daripada warna sebelumnya.
- Warna isi asal MAL, warna teks/ikon, bentuk FAB dan fungsi popup dikekalkan. Pertukaran warna berlaku pada tindakan pengguna atau perubahan status, tanpa animasi berterusan baharu.
- Menu ikon tiga garis di sebelah search bar, penapis A–Z, Random asal, Magic serta OAuth/login MAL dikekalkan. Tiada permission atau dependency runtime baharu.

## Versi dan build

- Version name **1.0.12**, version code **419**.
